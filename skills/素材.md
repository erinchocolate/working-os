# skill: 素材 —— 把 Notion / 阅读 / AI 聊天笔记提炼成可复用素材卡

**触发**：
- 「素材」+ 粘贴 Notion 笔记、文章摘录、AI 聊天摘要、worklog/thinking 片段、recurring 条目或学习笔记。
- 「素材卡 <主题>」→ 为某个主题沉淀素材卡。
- 「整理素材」→ 把一组笔记整理成多张素材卡。
- 「摄取素材」→ 同上；本触发优先于普通「摄取」。

**目的**：Notion 保留原始素材真源；`working-os/materials/` 只保存精选、可复用、能服务未来分享和思考的 Zettelkasten 素材卡。素材卡默认中文，以主人的总结为主，不复制长篇原文。素材卡是表达层，不是所有认知的终点。

## 先读
1. `AGENTS.md`（确认 working-os / context_platform 边界）。
2. `materials/index.md`（确认已有主题、来源和卡片，避免重复）。
3. 如果素材来自 worklog、thinking log、recurring、assets 或学习笔记，读对应来源，保留 origin 链路。
4. 如果输入包含明确项目事实、决策、workflow、用户反馈或 guideline，读对应的 `/opt/processes/context_platform` index，并把 shared context 路由到 context repo。

## 路由规则

| 信息类型 | 目标 |
|---|---|
| 可跨分享复用的想法、类比、观察、概念、表达素材 | `materials/cards/` |
| 某一次分享的主题地图、outline、talk track | `sharing/` |
| 项目事实、决策、坑、workflow、用户反馈、公司 guideline | `/opt/processes/context_platform` |
| 个人反思、工作方法、认知候选 | `worklog/` 和 `reviews/recurring.md` |
| 少量、已验证、会改变主人工作方式的原则 | `assets/mental-models.md` |

同一份输入可以拆成多份：可复用表达素材进 `materials/`，项目事实进 `context_platform`，个人反思进 `worklog/` 或 `recurring`，行动原则经系统复盘进入 `assets/mental-models.md`。

## 流程
1. 读取主人粘贴或导出的 Notion/阅读/AI 聊天内容，或指定的 worklog、thinking log、recurring、assets、学习笔记；短期不使用 Notion API。
2. 如果来源是 thinking worklog，优先处理 `material_candidate: yes / maybe` 的条目；不要把普通 thinking entry 自动转成素材卡。
3. 抽取 1-N 个原子素材卡。每张卡只承载一个主要想法；不要把整篇文章搬进一张卡。
4. 生成稳定 id：`<YYYY-MM-DD>-<short-slug>`，文件写到 `materials/cards/<id>.md`。
5. 用素材卡模板写卡片，默认中文；如果源材料是英文，也用中文总结，保留 source link 和 origin。
6. 同步更新 `materials/index.md`：按主题、来源和可复用场景索引新卡片。
7. 如果有适合当前分享的组织方式，只记录为候选；具体 theme map 由「分享」skill 写入 `sharing/`。

## 素材卡模板

```md
# <短标题>

- id: <YYYY-MM-DD-short-slug>
- source: <Notion / article / AI chat / talk / other>
- source_link:
- origin: <Notion link / worklog path / recurring canonical / assets/mental-models.md section>
- use_type: explanation / analogy / story / framework / question
- created: <YYYY-MM-DD>
- topics: [AI, Marvin, High Vis Docs, retrieval, communication]
- status: seed / developed / used

## 核心想法
- 用自己的话写一句最重要的 takeaway。

## 为什么对我有用
- 这条材料能帮助我理解什么、表达什么、或做什么判断。

## 可用于哪些分享
- 可能服务的主题、角度或听众。

## 关联卡片
- 暂无 / links to other material card ids.

## 原文短摘
- 可选。只放短 quote；不要复制长篇原文。
```

## index 更新规则

- `materials/index.md` 必须能找到每张卡。
- 新卡至少更新一个主题索引和一个来源索引。
- 如果卡片适合某个未来分享，加入「可用于哪些分享」索引。
- 更新已有卡片时，保留原 id；如观点发生明显变化，追加新段落，不静默覆盖旧语境。

## 原则

- 素材卡不是剪藏库；宁可少而清楚，不要把 Notion 全量搬进 repo。
- 素材卡是表达素材，不替代 `assets/mental-models.md` 的行动原则，也不替代完整学习笔记。
- 保留 source link，方便回到 Notion 或原文。
- 保留 origin，方便追溯到 worklog、thinking log、recurring、assets 或学习笔记。
- 限制长引用：只保留短 quote 和必要上下文，正文用主人的话总结。
- 不放敏感信息、公司私密原文、PII、凭证或长篇转载。
- `materials/` 可以进入个人 repo；共享项目/company context 仍写入 `/opt/processes/context_platform`，默认英文。
